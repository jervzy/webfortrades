Common questions

Common questions

Are DIY website builders any good?

Yes, for some people. If you have the time and enjoy building things yourself, tools like Wix, Squarespace and GoDaddy can work well. WebForTrades is for tradespeople who would rather have it built for them.

What is the difference in cost?

DIY builders are usually a monthly subscription you keep paying. WebForTrades offers a one-off payment so you own the site, or a monthly plan if you prefer. Either way the build is done for you.

Do I have to maintain it myself?

With DIY builders, yes. With WebForTrades, changes are included and I can update it for you, or you can use the optional editor.

Rather have it done for you?

I will build a free demo of your website. See it first, pay only if you want to keep it.
